# Senior Frontend Engineer (Next.js / TypeScript) – Refactor & Polish Solana Crash Trading Game UI

## Summary

I'm building a Solana-based crash trading game, similar in complexity and feel to rugs.fun.

The frontend is already implemented and functional, but it was developed by a junior engineer and now requires a full cleanup, refactor, and professional polish. The goal is to elevate the existing codebase to production-grade quality, improve performance, and deliver a smooth, precise gaming experience.

This is not a redesign and not a rewrite from scratch. The work focuses on correctness, stability, maintainability, and UX refinement.

## Current Frontend Stack

The project is currently implemented using:

- Next.js (App Router architecture)
- TypeScript (TSX)
- Tailwind CSS

While the technology stack is modern, the implementation quality does not yet meet production standards and needs senior-level refinement.

## Scope of Work

### 1. Codebase Cleanup & Refactor

- Remove unused and dead code
- Fix poor file structure and incorrect component placement
- Improve component separation and state management
- Correct common junior-level mistakes
- Make the codebase clean, readable, and maintainable

### 2. Canvas & Chart Issues

- Fix green/red canvas trimming issues
- Correct average price line behavior
- Resolve canvas background gradient spamming during buy/sell actions
- Ensure stable and deterministic canvas rendering

### 3. Trading Logic & UI Bugs

- Fix PnL spasms (PnL must freeze immediately after selling 100% of the position)
- Fix markers appearing one candle late after page refresh
- Fix markers sometimes moving forward with candles
- Ensure all markers and indicators behave predictably and correctly

### 4. Performance & Game Feel

- Improve overall smoothness and responsiveness
- Remove UI jitter, unnecessary re-renders, and rendering loops
- Optimize real-time updates and animations
- Deliver a fluid, professional gameplay experience comparable to rugs.fun
