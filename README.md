# Solana Crash Trading Game

A Solana-based crash trading game frontend built with Next.js, TypeScript, and Tailwind CSS.

## Overview

This project is a crash trading game similar to rugs.fun, built on the Solana blockchain. The frontend provides a real-time trading interface with live chart visualization, position management, and profit/loss tracking.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Blockchain**: Solana

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn
- Solana wallet extension (for production)

### Installation

```bash
npm install
# or
yarn install
```

### Development

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build

```bash
npm run build
# or
yarn build
```

## Project Structure

```
solana-crash-trading-game/
├── app/                 # Next.js App Router pages
├── components/          # React components
├── lib/                # Utility functions and helpers
├── hooks/              # Custom React hooks
├── types/              # TypeScript type definitions
└── public/             # Static assets
```

## Features

- Real-time crash game visualization
- Live chart rendering with Canvas
- Position management (buy/sell)
- Profit & Loss tracking
- Responsive design
